# cryptopals

*(In progress.*

*Last updated: 1/6/2025)*

Attempted solutions to [the cryptopals (Matasano) crypto challenge](https://cryptopals.com/) in Python.

## Usage

```bash
git clone https://github.com/Xiaoran-Gao/cryptopals
cd cryptopals
python3 <set>/<challenge>.py
```
